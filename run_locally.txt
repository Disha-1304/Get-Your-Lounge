LOUNGEPAIR INTERNATIONAL - LOCAL SERVER RUN GUIDE & FEATURES SUMMARY
========================================================================

--- HOW TO RUN THE WEBSITE LOCALLY ---

You can start the local PHP server using the local PHP executable included in this project folder:

Command (run from this project directory in PowerShell or Command Prompt):
------------------------------------------------------------------------
.\php-bin\php.exe -S localhost:8000
------------------------------------------------------------------------

Once the server is running, open your web browser and navigate to:
http://localhost:8000

--- WHAT THE WEBSITE CURRENTLY CAN DO (FEATURES SUMMARY) ---

1. Homepage (index.php):
   * Dynamic Autocomplete Search: Type in a city or lounge to see instant matches.
   * Direct Booking Navigation: Clicking an item in the autocomplete dropdown redirects you directly to the search page and auto-opens the booking modal for that specific lounge.
   * Search Submission: Submitting the hero search bar redirects you to the live search page with your search query pre-filled.

2. Search Results Page (search.php):
   * Real-time Interactive Filtering: Filter all 10 premium lounges instantly using the left sidebar:
     - Budget (USD range slider & inputs)
     - Minimum Rating (Any, 4.0+, 4.5+, 4.9+)
     - Region (Americas, Asia, Europe, Middle East) with real-time count badges
     - Availability Status (Quiet & Spacious, Moderate, High Demand)
     - Amenities list (Cigar bars, spas, sleep pods, dim sum stations, etc.)
   * Active Filter Chips: Applied filters display as chips above the results. Clicking a chip's "x" or clicking "Clear all" resets the filters instantly.
   * Dynamic Sorting: Sort lounges by Top Rated, Price (Low to High, High to Low), Most Reviewed, and Alphabetical (A to Z).
   * List vs. Grid View: Toggle between horizontal cards layout and grid card layout.
   * Premium Cards Design:
     - Visual Zoom Hover & "Save to Favourites" heart buttons on images.
     - "🔥 Trending" animation badges for top-rated lounges.
     - Live currency conversions synced globally in the sticky header.
     - Real-time availability indicators (🟢, 🔵, 🟡).
   * Integrated Inline Modals:
     - Virtual Tour: Opens interactive image carousels for the lounge interiors.
     - Book Now: Launches the fully functional inline booking modal. Confirming a booking triggers a canvas-confetti celebration.
   * Direct Modals Linking: Navigating to search.php?q=<city>&id=<lounge-id> auto-opens the Booking Modal for the specified lounge on arrival.
